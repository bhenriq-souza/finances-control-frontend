# ADRs locais do frontend

Decisões **restritas a este repositório**: organização interna, troca de uma peça do kit do [ADR-0001 do hub](https://github.com/bhenriq-souza/finances-control/blob/main/docs/adr/ADR-0001-frontend.md), escolha pontual de biblioteca.

Decisões de **produto e arquitetura macro** vivem no repositório hub, em [`docs/adr/`](https://github.com/bhenriq-souza/finances-control/tree/main/docs/adr). Não duplique aqui: referencie por link.

Formato: `NNNN-titulo-kebab.md`, com frontmatter `status: accepted | superseded` e as seções **Context**, **Decision**, **Consequences**, **Alternatives considered** (spec 0000). ADRs são imutáveis depois de aceitos — para mudar, crie um novo que supersede o anterior.
